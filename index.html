The Birthday Paradox

The birthday paradox presents the theory that if you are in a room with 23+ people then there is a little over a 50% chance that you share a birthday with someone. The problem that we solved was that if we were to randomly generate the birthdays of those people that we would in fact get matching birthdays over 50% of the time.

Functional requirements/what the project does The core requirements that were needed for this project were the 4 main classes. The Birthday class was used to create and assign a birthday to a person. The Trial class's would assign birthdays to a group and see if there was a match. The Experiment class runs the trials multiple times and checks for all probabilities. Finally, the Simulator class runs the experiments and reveals the results.

Project Implementation The role I played in this project was writing the Trial and Experiment classes
